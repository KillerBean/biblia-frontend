# Política de segurança

Relate vulnerabilidades de forma privada ao owner do projeto ou por GitHub
Security Advisory. Não publique detalhes exploráveis em issues ou pull
requests.

Inclua versão do app, plataforma, passos para reproduzir, impacto e uma
prova de conceito mínima quando possível. Confirmaremos o recebimento em até
7 dias e manteremos o reporte restrito durante a correção.

O escopo inclui o app Flutter, o banco offline, o cliente HTTP e os artefatos
de release. Não inclua dados pessoais ou credenciais reais no reporte.
